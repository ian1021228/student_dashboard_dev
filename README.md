# 班級經營系統 — 學生數位聯絡簿與成績登記端 (Student Dashboard)

> **自主學習、數位聯絡、自我管理，全面告別紙本聯絡簿！**  
> 由高雄市立七賢國中 107 王禹硯（國一生）獨立編程打造，專為學生日常作業自主勾選、108 課綱 21 門領域學科成績登記、7 天歷史聯絡簿查閱、生活心得隨筆與 PWA 桌面化設計。

---

## 📌 系統全景與設計初衷

身為國中學生，深知傳統紙本聯絡簿的諸多不便：每天放學前趕著抄寫、課本作業本帶回家卻忘記聯絡簿放哪裡、錯題小考成績零散記錄難以系統化追蹤。  
**學生數位聯絡簿端**旨在為學生提供一個專屬、自主、直覺的學習管理平台，讓每位同學都能養成自我檢視與學習反思的良好習慣。

---

## 🎒 核心功能亮點

### 1. 今日作業自主檢核清單
- **雙向比對確認**：學生可在本端自主勾選作業完成進度（已完成 / 未完成），介面同時呈現導師在教師端的即時點收結果（已繳交、待訂正、缺交），清楚了解自己的收件狀態。
- **作業進度環形進度條**：直觀視覺化今日總體完成率，督促自己準時完成所有作業。

### 2. 臺灣 108 課綱 21 門學科小考成績登記（兩列可收合設計）
- **兩列式靈活分類按鈕**：
  - **第一列：常用主科快速分類**：`國語`、`數學`、`英語`、`自然`、`社會`、`其他`（點擊即可帶入常用主科，支援展開/收合切換）。
  - **第二列：臺灣 108 課綱 6 大領域 21 門學科詳細分類**（可展開/收合）：
    1. **語文領域（2 門）**：國語文、英語文
    2. **數學領域（1 門）**：數學
    3. **社會領域（4 門）**：歷史、地理、公民與社會、**綜合社會**
    4. **自然科學領域（4 門）**：生物、理化、地球科學、**綜合自然**
    5. **藝術與科技領域（5 門）**：音樂、視覺藝術、表演藝術、資訊科技、生活科技
    6. **健體與綜合活動領域（5 門）**：健康教育、體育、家政、童軍、輔導
- **全方位成績與訂正紀錄**：
  - 支援得分與滿分輸入（自動換算為百分制）。
  - 訂正狀態勾選：已完成訂正 / 待訂正。
  - 錯題檢討與加強心得備忘錄，協助考後即時複習。

### 3. 學生個人專屬 6 位數驗證碼 (PIN 碼) 機制
為保護學生在校個人成績隱私，系統建構嚴密的四重安全機制：
- **導師開通先決條件**：必須等到教師在後台設定該學生 PIN 碼後，學生與家長方可進入成績系統。若未開通，介面將友善提示「導師尚未開通專屬驗證碼」。
- **首次綁定**：學生在自己的手機或電腦首次點選自己的座號時，系統提示輸入「學生個人 6 位數專屬密碼」（預設為 `100000 + 座號`）。
- **本機免密直開（便利）**：本機瀏覽器（LocalStorage）會自動記憶已驗證的憑證，學生平時使用自己的手機或電腦打開時完全免重複輸入密碼。
- **跨座號防窺防護（安全）**：若在同一裝置上試圖切換至「其他同學的座號」，或其他人從別的裝置點選該座號時，系統必須要求輸入該座號的專屬 PIN 碼，否則拒絕存取並鎖定畫面，徹底杜絕他人任意切換偷看。
- **導師重設後門**：若學生忘記密碼，教師端「成績系統」後台提供「一鍵重設座號密碼」功能，避免學生因忘記密碼而無法使用。

### 4. 過去 7 天聯絡簿時間軸
- **橫向滑動歷史軸**：提供一週 7 天聯絡簿快速切換，請假補課、查閱昨日作業或回溯導師叮嚀免求人。

### 5. 今日生活心得隨筆（心情札記）
- **生動心情表情選擇**：五種心情狀態（😄 開心、💪 充實、😌 平靜、😓 疲憊、😢 沮喪），自由標記今日心情。
- **給老師與爸媽的一句話**：文字輸入框供學生隨筆抒發今日收穫、班級趣事或遭遇的困難，取代實體聯絡簿心情生活欄。

### 6. 一鍵產生 LINE 回報文字
- 點擊「一鍵複製回報格式」，系統自動將今日完成的作業、小考成績與生活隨筆排版為乾淨工整的純文字，方便複製貼至家庭 LINE 群組向家長報備。

### 7. 📲 Progressive Web App (PWA) 支援
- **一鍵安裝至桌面**：支援 PWA 標準規範，Chrome/Edge 等桌面與 Android 手機在「系統設定」可一鍵點擊「安裝至桌面/主畫面」。
- **iOS 專屬安裝引導**：針對 iPhone/iPad Safari 使用者提供精緻的「加入主畫面」圖文引導彈窗，享受如原生 App 般的沉浸式全螢幕操作體驗。

### 8. 🛡️ 全站內自訂互動與問題回報
- **全站內自訂彈窗**：不論是提示訊息、密碼輸入或修改確認，全程採用網頁內部高質感 Modal，完全杜絕瀏覽器預設上方灰色彈窗。
- **意見反映與系統問題回報**：設定視窗與頁尾皆內建「回報系統問題 / 提供建議」直達按鈕，連結至專屬 [Google 回饋表單](https://docs.google.com/forms/d/19BPzX6vMrSnvW3j2s4OOvaiP3p1gS8auGbRt3f9aFkM/edit)，隨時傾聽同學的使用心聲。

## 🛠️ 技術規格

- **架構**：原生 Vanilla JavaScript (ES6+ Modules)
- **UI 與排版**：Tailwind CSS (響應式設計，手機 393×852 觸控模擬與平板、電腦端皆平滑適配)
- **圖示庫**：FontAwesome 6 Free/Pro
- **資料庫**：Google Firebase Cloud Firestore 9.x（即時雙向監聽與本地 LocalStorage 快取）
- **PWA**：Web App Manifest + Service Worker 離線快取
- **託管**：GitHub Pages 靜態網站
